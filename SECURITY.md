# Security policy

## Supported versions

Only the latest release and `master` get fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Report privately through [GitHub private vulnerability reporting](https://github.com/mariusDing/sports-video-coach/security/advisories/new). You should get a first reply within 7 days.

This also covers **privacy problems**, for example a feature that could leak player names, frames or local paths into a shared report. Do not include real player data in the report; describe the problem or use synthetic data.
