**一句话：** 每次转身都像 **00:09** 那次：**0.5 秒**，不是 **1.5 秒**。

## 1. 三次转身有两次在锥桶前停住

![方块在右侧锥桶停了 1.5 秒](clip:00:02-00:08)

**录像里看到的**
- **00:04**：在右侧锥桶停 **1.5 秒** 才往回跑
- **00:14**：同样停住，又是 **1.5 秒**

![00:14 又一次停住](clip:00:13-00:18)

**为什么会这样**
- 可能：全速冲到锥桶，只能先急停再转身
- 不清楚：画面看不到脚步

**正确的样子**
- **两步小碎步，外侧脚踩住，蹬回去**

**练习**
- **锥桶转身：6 × 10 米**，每次喊"小、小、踩"

**下次怎么检查**
- 每次转身 **少于 0.8 秒**：四段总时间 **少于 18.5 秒**（现在 19.5 秒）
